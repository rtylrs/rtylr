# Frequently Asked Questions

Answers to common questions about rtylr.

## What are the pricing plans?

rtylr offers tiered pricing based on features and usage. All plans include core apps (Hub, POS, ERP). Higher tiers unlock additional apps, more team members, and premium addons. Visit **rtylr.com/pricing** for current plans and pricing. All plans include a free trial period.

## How is my data protected?

All data is encrypted in transit (TLS 1.3) and at rest (AES-256). Each organization's data is isolated at the database level. rtylr follows industry-standard security practices including regular penetration testing, SOC 2 compliance, and automated backups. You own your data and can export it at any time.

## What payment methods does POS support?

POS supports cash, credit/debit cards (via integrated payment terminals), gift cards, store credit, and split payments. Specific payment terminal hardware compatibility depends on your region. Contact support for a list of supported devices.

## Does rtylr work offline?

Yes. The POS app is designed to work offline. When the internet connection drops, orders and payments are stored locally and automatically sync when connectivity is restored. Other apps require an active connection but will gracefully handle intermittent connectivity.

## Does rtylr support multiple languages?

The admin interface is available in English with more languages in development. For customer-facing content (Store, booking pages, emails), the Multi-Language addon lets you translate content into any supported language. Right-to-left (RTL) layouts are supported.

## Can I use my own domain?

Yes. With the Custom Domain addon, you can connect your own domain to your Store and booking pages. rtylr handles SSL certificate provisioning automatically. DNS configuration instructions are provided during setup.

## Is there an API?

Yes. rtylr provides a RESTful API for programmatic access to your data. The API supports all core operations and uses bearer token authentication. See the [API Overview](/api/overview) for details. API access is available through the API Access addon or included in higher-tier plans.

## Can I export my data?

Yes. Most apps support CSV and PDF export for individual reports and lists. The Data Export addon provides bulk export of all your organization's data in standard formats (CSV, JSON) for compliance or migration purposes.

## Is there a mobile app?

rtylr is a responsive web application that works on tablets and mobile devices. The POS app is optimized for tablet-size screens. A dedicated mobile app for staff (shift clock-in, schedule viewing, task management) is on the roadmap.

## What third-party integrations are available?

rtylr integrates with payment processors, accounting software, email providers, SMS gateways, and shipping carriers. Integrations are managed in **Hub > Settings > Integrations**. For custom integrations, use the API and webhook system.

## How do I get support?

All plans include email support. The Priority Support addon provides faster response times and a dedicated account manager. Documentation, guides, and FAQs are available at **docs.rtylr.com**.
